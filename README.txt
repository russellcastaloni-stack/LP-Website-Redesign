Launchpad Advertising website (plain HTML/CSS/JavaScript, no build step)

index.html        page shell (header, footer, loader)
css/styles.css    all styles and animations
js/images.js      image path map (edit to swap photos)
js/app.js         pages, routing (#about, #services ...), animations
assets/img/       photos, logo and rocket files

Open index.html in a browser, or upload the whole folder to any web host.
Fonts load from Google Fonts (Montserrat).
